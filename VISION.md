# VISION

The purpose of this project is to identify the places you may drive to (perhaps with bit of a walk added on top of driving) where you can see far away horizon with decent field of view in clear so you can watch sunsets, sunrise , moon rise etc. This is very useful in place like Washington state where the area is fairly hilly and people often ask where can we go to see the sunset.

There are 3 main issues that makes exact specifications for this project bit difficult:

1. The far away horizon may not be actual horizon but may be horizon is blocked by another mountain range. This is still ok as long as we can see far enough.
2. At the view point there may still be trees, not allowing any actual views.
3. We need to consider drivability properly because we need to be able to park car somewhere and we may be willing to walk for few minutes from there to actual view points.

The program should be able to provide graphical UX that is beautiful, highly informative and usable so its extremely easy to identify, select, navigate and drive to a place.

The program should work offline as much as possible by building road network and terrain maps and may be other POI information that makes it easy to identify close by places.
